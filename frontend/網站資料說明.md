# 網站資料修改說明

這個網站目前沒有後端或資料庫，所有會顯示在網站上的文字資料都放在 `frontend/src/data` 資料夾中。這樣做的好處是：初學者只需要修改少數幾個檔案，就能更新網站內容。

## 資料放在哪裡？

```text
frontend/src/data/
├── profile.js       個人基本資料
├── products.js      商品資料
└── experiences.js   經歷資料
```

## 修改個人基本資料

開啟 `frontend/src/data/profile.js`，可修改：

- `name`：姓名
- `title`：職稱
- `shortIntro`：首頁的簡短介紹
- `about`：關於我的詳細介紹
- `email`：聯絡 Email
- `socialLinks`：社群連結或個人網站

例如要改 Email，找到下面這一行並換成自己的 Email：

```js
email: 'hello@example.com',
```

## 修改商品資料

開啟 `frontend/src/data/products.js`。每一組用 `{ }` 包起來的內容就是一個商品；目前有三筆商品資料。

每筆商品可修改的欄位如下：

- `id`：商品編號，每一筆都必須不同
- `name`：商品名稱
- `image`：商品圖片路徑
- `category`：商品分類的小標籤
- `intro`：卡片上的簡短介紹
- `description`：點開商品後顯示的詳細介紹
- `audience`：適合對象
- `price`：價格或合作方式

新增商品時，複製最後一個商品的完整 `{ ... }` 區塊，貼在下一行，並將 `id` 改成新的數字，例如 `4`。記得上一筆資料結尾要保留逗號 `,`。

## 修改經歷資料

開啟 `frontend/src/data/experiences.js`。每一組 `{ }` 就是一段經歷。

每筆經歷可修改的欄位如下：

- `id`：經歷編號，每一筆都必須不同
- `title`：經歷標題
- `image`：經歷圖片路徑
- `date`：日期或年份
- `intro`：列表上的簡短說明
- `story`：點開經歷後顯示的詳細故事
- `result`：相關成果

新增方式和商品相同：複製一整組 `{ ... }`，貼到陣列的最後，並換成新內容與不重複的 `id`。

## 圖片要放在哪裡？

商品圖片請放在：`frontend/商品圖片`

經歷圖片請放在：`frontend/經歷圖片`

資料夾結構如下：

```text
frontend/
├── 商品圖片/
│   ├── product-1.jpg
│   ├── product-2.jpg
│   └── product-3.jpg
└── 經歷圖片/
    ├── experience-1.jpg
    ├── experience-2.jpg
    └── experience-3.jpg
```

## 圖片名稱建議

建議使用英文、小寫字母、數字和連字號 `-` 命名，不使用空白或特殊符號。例如：

```text
商品圖片/product-candle.jpg
商品圖片/product-gift-set.jpg
經歷圖片/experience-brand-project.jpg
經歷圖片/experience-workshop-2026.jpg
```

放入新圖片後，別忘了同步修改資料檔中的 `image` 路徑。例如圖片檔名是 `product-candle.jpg`，商品資料請寫成：

```js
image: '/商品圖片/product-candle.jpg',
```

圖片尚未放入時，網站會自動顯示預設漸層佔位圖，不會影響其他內容。

## 修改後怎麼確認？

網站正在執行 `npm run dev` 時，儲存資料檔後瀏覽器通常會自動重新整理。如果沒有變化，請手動重新整理瀏覽器頁面。
